# SkillSync
• Developed a mobile app for streamlined communication between faculty and students, centralizing events like hackathons and workshops. The app enables easy event posting and registration.
# 🚀 Features
- **Event Announcements** – Faculty can post updates about hackathons, workshops, and seminars.
- **Mobile-Friendly UI** – Simple and intuitive design for seamless navigation.
- **Easy Registration** – Students can register for events with a single tap.
- **Role-Based Access** – Separate features and permissions for students and faculty.
- **Seamless Navigation** – No need to search manually; users can easily navigate between different sections.
# 🛠️ Technologies Used
- Android Studio (Java, XML)
- Firebase Real-Time Database (Login, storing event details, etc.)
